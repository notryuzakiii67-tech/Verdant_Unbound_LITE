# VERDANT — UNBOUND LITE
## Installation Documentation

### Prerequisites
- **Minecraft Java 1.21.11**
- **Fabric Loader**
- **Iris Shader Loader**
- **Sodium Renderer**
- **Fabulously Optimized Modpack** (optional but recommended)
- **Target Hardware**: ASUS X405UQ (Intel Core i5 7th gen, NVIDIA GeForce 940MX, 8 GB RAM)

### Installation Steps

1. **Download the Shaderpack**
   - Download `VERDANT_UNBOUND_LITE.zip`
   - Extract if necessary (keep directory structure intact)

2. **Install Minecraft Components**
   - Install Minecraft Java 1.21.11
   - Install Fabric Loader for 1.21.11
   - Install Iris Shader Loader
   - Install Sodium Renderer
   - Install Fabulously Optimized Modpack (optional)

3. **Place Shaderpack**
   - Navigate to `.minecraft/shaderpacks` directory
   - Place `VERDANT_UNBOUND_LITE.zip` in the directory
   - Do not extract the ZIP file

4. **Configure Minecraft**
   - Launch Minecraft with Fabric profile
   - Select "Verdant — Unbound Lite" in shader options
   - Choose appropriate preset (Balanced Ultra-Lite recommended for ASUS X405UQ)

5. **Optimize Settings**
   - **Potato**: Extremely low-end hardware
   - **Lite**: Maximum practical performance
   - **Balanced Ultra-Lite**: Default recommended (ASUS X405UQ)
   - **Quality**: Better visuals with low-end awareness

6. **Test Installation**
   - Launch a world in 1.21.11
   - Verify shader loading
   - Check performance (target: 30+ FPS on ASUS X405UQ)
   - Test all presets

### Troubleshooting

#### Common Issues
1. **Shader not loading**
   - Check Minecraft version (must be 1.21.11)
   - Verify Iris and Sodium installation
   - Ensure ZIP structure is correct

2. **Low performance**
   - Switch to Potato or Lite preset
   - Reduce shadow distance
   - Disable expensive effects (bloom, reflections)
   - Lower resolution

3. **Visual artifacts**
   - Update graphics drivers
   - Reduce shadow quality
   - Disable advanced effects

4. **Dimension switching issues**
   - Ensure dimension support is enabled
   - Check transition progress settings

#### Performance Targets (ASUS X405UQ)
- **Potato**: 45+ FPS (720p)
- **Lite**: 35+ FPS (720p)
- **Balanced Ultra-Lite**: 30+ FPS (720p)
