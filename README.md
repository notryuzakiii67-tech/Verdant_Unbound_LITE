# Verdant — Unbound Lite
# Original Minecraft Shaderpack | Minecraft Java 1.21.11 | Fabric | Iris | Fabulously Optimized

## Overview
Verdant — Unbound Lite is a complete shaderpack engineered specifically for low-end and older NVIDIA GPUs, particularly the NVIDIA GeForce 940MX, while visually approaching the appearance of Complementary Unbound.

## Target Hardware
- **GPU**: NVIDIA GeForce 940MX (ASUS X405UQ)
- **CPU**: Intel Core i5 7th generation
- **RAM**: 8 GB
- **Storage**: 1 TB HDD
- **Shader Loader**: Iris
- **Renderer**: Sodium
- **Modpack**: Fabulously Optimized for Minecraft 1.21.11

## Installation
1. Download `VERDANT_UNBOUND_LITE.zip`
2. Place the ZIP file in the `.minecraft/shaderpacks` directory
3. Launch Minecraft 1.21.11 with Fabric, Iris, and Sodium installed
4. Select "Verdant — Unbound Lite" in the shader options
5. Choose the appropriate preset for your hardware (Balanced Ultra-Lite recommended for ASUS X405UQ)

## Presets
- **Potato**: Extremely low-end hardware optimization
- **Lite**: Maximum practical performance
- **Balanced Ultra-Lite**: Default recommended for ASUS X405UQ (best balance)
- **Quality**: Better visuals while maintaining low-end GPU awareness

## Features
- Realistic lighting system with day/night transitions
- Efficient shadow system with configurable quality
- Beautiful water system with reflections and animation
- Realistic sky and cloud systems
- Natural vegetation animation
- Weather-dependent effects
- Material shading improvements
- Optimized bloom and post-processing
- Full dimension support (Overworld, Nether, End)
